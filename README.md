# Palimpsest

원문과 판단 근거를 보존하는 로컬 지식 Wiki다. Python/Docker backend와 Electron 앱으로 Data·Information·Knowledge, 설명 Wisdom과 Parchment를 연결한다.

구현 버전, 검증 범위, 남은 작업은 **[현재 상태](progress/STATUS.md)** 한곳에서 관리한다. 작업에 필요한 계약은 [문서 인덱스](docs/INDEX.md)에서 선택한다.

## 실행

기존 설치 환경에서 [Palimpsest.cmd](Palimpsest.cmd)를 실행한다. 런처는 공용 Electron 엔진과 보존된 앱 패키지를 사용한다. 설치 구성과 저장소 연결은 [통합 Desktop](docs/interfaces/UNIFIED_DESKTOP.md), 명령별 사용법은 [CLI 계약](docs/interfaces/CLI_CONTRACT.md)과 해당 기능 계약을 따른다.

## 개발 시작

- 작업 범위와 보존 규칙: [AGENTS.md](AGENTS.md)
- 현재 구현·검증·다음 작업: [progress/STATUS.md](progress/STATUS.md)
- 기능별 계약·과거 기록 찾기: [docs/INDEX.md](docs/INDEX.md)

과거 실행 보고서는 당시의 결과다. 현재 상태나 새 자료의 실행 권한으로 해석하지 않는다. 로컬 Git의 최초 기준점과 이전 진입 문서 조회 방법도 [문서 인덱스](docs/INDEX.md)에 있다.
