# I2K는 원문 정리, 새로운 결론은 K2K

2026-09-11 최신 사용자 정정. **I2K에서는 원문에 없는 결론·추측을 도출하지 않는다. 시스템의 새로운 귀납·연역 결론은 K2K만 생성한다.** 앞선 [다중 Data I2K](MULTI_SOURCE_I2K.md)와 [추론 표시](LLM_WIKI_RETRIEVAL.md)의 “I2K도 새 결론을 도출할 수 있다”는 설명을 이 범위에서 대체한다. 여러 D의 I를 함께 사용하는 요구와 실제 실험 요청은 유지한다.

## 원문 통합과 새 결론의 경계

I2K는 여러 D에서 온 하나 이상의 I에 **명시된 내용**을 선택·정규화·구조화하여 하나의 K 후보로 만들 수 있다. 동일한 의미의 주장과 근거를 통합하거나 같은 대상의 명시적 설명·조건을 모을 수 있지만, 새로운 사실·인과관계·일반화·예측·가설을 추가하지 않는다. DB에 아직 없던 KNode를 생성하는 것과 원문에 없던 결론을 도출하는 것은 구분한다.

| 작업 | 처리 |
|---|---|
| 여러 원문이 같은 명제를 보고함 | I2K에서 하나의 K로 정리·재사용하고 각 exact I 근거를 연결 |
| 원문에 명시된 같은 대상의 설명·조건을 함께 정리 | I2K에서 대상·범위가 같은지 검증하고 원문 의미를 유지 |
| 원문 A의 관계와 원문 B의 관계에서 새로운 관계를 추론 | I2K에서 결론을 만들지 않음. 필요한 전제 K를 검증한 뒤 K2K가 도출 |
| 여러 실험에서 보편적 효과나 기전을 추측 | K2K의 귀납 후보로 다루고 범위·반례·불확실성을 검증 |
| 원문 저자의 결론·가설을 그대로 귀속해 보고 | I2K에서 reported Proposition으로 정리. 시스템의 새 추론이나 Observation으로 위장하지 않음 |

자료를 합치는 것만으로 인과관계나 동일 실험임을 가정하지 않는다. 서로 다른 출처의 유사 Observation과 source-specific 결과는 그대로 구별한다. K의 의미 scope와 evidence Data 집합도 구분한다. 일반 사실의 같은 의미에 근거가 추가되면 K/semantic Revision을 늘리지 않는다.

[직접 D 예외](I2K_DIRECT_SOURCE_EVIDENCE.md)도 동일한 원칙을 따른다. 원본 D에서 실제 확인한 명시 내용을 직접 grounding으로 연결할 수 있지만, 원본을 읽었다는 이유로 I2K의 추측·새 결론 생성을 허용하지 않는다. D2I 재실행이나 새 I 생성으로 근거를 꾸미지 않는다.

## 생성 기원과 검증

- 새 I2K-origin Revision은 `origin_operation=i2k`, `is_inferred=false`다. 정확한 I 또는 승인된 직접 D 근거와 독립 Validator의 원문 지지 판정을 연결한다.
- 새 추론 결론은 K2K가 accepted/current-applicable KRevision·EffectiveEdge를 전제로 생성한다. 실제 K2K origin, `is_inferred=true`, 검증된 귀납/연역 유형·전제·가정·한계·검증을 보존한다.
- 원문 저자가 수행한 추론을 I2K로 전달한 경우는 시스템이 새로 추론한 것이 아니다. 저자 귀속과 원문의 불확실성을 유지한다.
- I2K가 기존 추론 K와 같은 의미를 재사용하거나 직접 원문 근거를 추가하더라도 그 기존 Revision의 추론 생성 기원을 바꾸지 않는다. K2K가 기존 직접 원문 K를 재사용할 때도 최초 기원을 유지하고 추가 도출 Record만 연결한다.

`is_inferred=false`를 모델이 출력했다는 사실만으로 원문 지지가 입증되지는 않는다. Generator와 Validator는 신규 사실·인과·범위 확대가 없는지 실제 근거로 검사하고, 스크립트는 허용 operation·기원 metadata·exact refs·입력 현재성·atomic 저장을 검사한다. 원문이 지지하지 않는 I2K 후보는 canonical K로 반영하지 않는다. 새로운 추론이 필요한 경우의 K2K 경로와 단순 원문 부족을 구분한다.

## 이번 작업과 확인할 결과

사용자는 이 정정과 함께 **서로 다른 D의 I를 사용하는 실제 I2K 실험**을 요청했다. 문서만 정리한 상태에서 완료라고 보고하지 않는다. [다중 Data Runtime 실행 계획](../../progress/T04_multi_source_runtime_execplan.md)에 구현·migration·실제 모델 호출·PostgreSQL 반영·재사용 결과를 구분해 기록한다. 이 결정문서는 해당 실행이나 K2K 구현이 이미 완료됐다는 뜻이 아니다.

최소 확인 사항은 여러 D의 명시 내용을 근거로 한 K의 exact provenance, 다른 실험의 보존, 의미가 같은 기존 K의 재사용, I2K 신규 추론 후보의 차단, 신규 I2K origin의 `is_inferred=false`, 기존 추론 origin 재사용 시 불변성이다. D2I 호출·I 수정은 0이어야 하며 실제 다중 Data 실행 결과와 단순 문서·mock 검사를 구별한다.
