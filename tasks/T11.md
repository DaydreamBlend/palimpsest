## 구현 순서

1. CLI review list/show/resolve와 candidate preview, input/grounding/effect inspection을 연결한다. 잘못된 승인이나 stale payload를 차단한다.
2. propagation pending/partial/blocked/anomaly와 pause/resume/cancel을 terminal/JSON에서 정확히 표시한다.
3. current/historical knowledge와 reported decision/authority-confirmed event를 구분하고 explicit confirmation을 요구한다.
4. 비TTY 입력 누락·거부·취소·권한 오류를 무한 prompt 없이 안정된 JSON/exit로 반환한다.
5. 실제 CLI headless e2e를 수행한다. 웹/desktop GUI, graph visualization, GUI 전용 API는 이 task에서 구현하지 않는다.

## 변경 범위

CLI adapter, application service 연결, command/result schemas, CLI tests와 운영 안내만 변경한다. GUI/framework/브라우저 surface는 T13로 미룬다. 기존 GUI가 있으면 삭제하지 않고 동결한다. 새로운 remote provider나 multi-tenant deployment는 별도다.
