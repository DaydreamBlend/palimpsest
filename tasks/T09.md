## 구현 순서

1. payload-bound confirmation command와 W 생성 전 event idempotency를 구현합니다.
2. action schema와 deterministic mapping, W/K/Record/provenance/outbox atomic commit을 구현합니다.
3. 동일 사건 retry/진짜 재결정/정정/future-effective/partial supersession을 분리합니다.
4. authority_confirmed와 reported decision trace를 각각 W/confirmation 및 I/D로 수행합니다.

## 변경 범위

authority/decision/W2K/trace와 user confirmation surface. LLM이 confirmation evidence를 만들거나 W2K 재해석을 하게 하지 않습니다.

실제 code 경로는 T00 inventory의 module ownership map을 사용합니다. 제안 경로만 보고 기존 프로젝트를 재배치하지 않습니다. 새로운 production dependency는 기존 정책과 승인을 따릅니다.
