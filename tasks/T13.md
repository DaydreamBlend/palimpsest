# T13 — GUI: CLI release 이후 마지막 단계

> 현재 상태: IN_PROGRESS — 2026-09-13 사용자가 Electron UI 구현을 명시적으로 지시했다. [첫 읽기 UI](../docs/interfaces/DESKTOP_UI.md)를 구현·검증했으며 전체 T13/CLI release 완료는 아니다. [후속 승인](../docs/decisions/ELECTRON_UI_START.md)이 아래 원래 착수 순서에 이 범위에서 우선한다.

## 원래 선행 조건과 착수 gate

T12 CLI release가 실제로 완료되고 사용자가 이후 GUI 착수를 명시적으로 지시한 경우에만 시작한다. 두 조건이 없으면 frontend scaffold, GUI toolkit, browser dashboard, GUI 전용 API를 추가하지 않는다. T00–T12는 이 task에 의존하지 않는다.

## 마지막 단계의 범위

그 시점에 GUI 목표/사용 흐름/framework를 검토한다. Artifact Store/Canonical Store/Compiler Runtime과 이미 검증된 application services를 재사용한다. CLI에서 구현한 confirmation/validation/provenance/propagation을 GUI에 복제하거나 우회하지 않는다.

## 검증과 완료

현재 이 task와 연결된 AT103은 GUI가 앞당겨지지 않는 release gate 검사다. 실제 GUI 기능 acceptance는 착수 후 별도로 정의한다. GUI completion을 지금부터 선언하지 않는다. 새 GUI가 CLI 동작/권한/비대화형 자동화를 깨뜨리지 않는 회귀 검사를 포함한다.
