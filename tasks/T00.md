## 구현 순서

1. 기존 git 상태/사용자 변경/AGENTS/manifests/lockfiles를 read-only로 조사한다. secret 본문은 출력하지 않는다.
2. Artifact Store/Canonical Store/Compiler Runtime에 해당하는 현재 code/schema/path와 old-name mapping을 기록한다.
3. CLI entrypoint/library/help/test 상태, GUI에 결합된 application services, headless 실행 가능 여부를 확인한다.
4. OS/architecture/GPU/runtime/memory와 MinerU 설치 여부/version/help, model readiness, local/remote config를 안전하게 조사한다. 자동 설치·download·PDF 전송은 하지 않는다.
5. 기존 검증 명령을 실행 가능한 안전 범위에서 확인하고 progress inventory/STATUS를 갱신한다. CLI 우선/MinerU 선택/이름 변경을 다시 승인 질문으로 돌리지 않는다. 나머지 P12 기술 선택은 미정으로 보고한다.
