## 구현 순서

1. W refs/direct K/I refs와 citation mapping을 보존하는 P 생성/편집 경로를 구현합니다.
2. Book의 ordered sections와 exact parchment IDs를 고정합니다.
3. export/import origin linkage를 구현하고 독립 evidence 중복 계산에서 파생 원문을 구분합니다.
4. 새 문장/인용 이동/출처 없는 author edit를 검증하거나 표시합니다.

## 변경 범위

publication/export/import lineage와 최소 editor/draft adapter. 새 WisdomRevision/ParchmentRevision/BookRevision wrapper는 만들지 않습니다.

실제 code 경로는 T00 inventory의 module ownership map을 사용합니다. 제안 경로만 보고 기존 프로젝트를 재배치하지 않습니다. 새로운 production dependency는 기존 정책과 승인을 따릅니다.
