## 구현 순서

1. approved embedding/lexical profile adapters와 authoritative filtering/index watermark를 구현합니다. 최초에는 mock projection도 허용하되 명시합니다.
2. evidence mode/retrieval strategy의 승인된 schema와 exact effective inputs/graph read receipt를 보존합니다.
3. claim-level citations, direct I vs accepted K 표시, conflicts/pending/uncertainty를 출력합니다.
4. QueryContextGraph를 runtime overlay로 제한하고 일반 W의 자동 W2K/과거 Query 자동 실행을 차단합니다.
