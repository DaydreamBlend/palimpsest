# T04 — I2K·KNode·materiality·CAS

**2026-09-13 최신 사용자 정정:** [I-only·D2I 오류 보고](../docs/decisions/I2K_INFORMATION_ERRORS.md)가 아래 직접 D grounding 후속 요구를 철회한다. source K는 실제 I에서만 만들며, I 부족/전사/이미지/provenance 문제는 사용자에게 보고하고 관련 후보를 보류한다. D2K·직접 D 지원 추가·자동 D2I 복구를 구현하지 않는다. [현재 실행 계획](../progress/T14_source_issues_execplan.md)을 따른다.

2026-09-11 최신 정정과 실행 요청: [I2K 원문 정리·새 결론은 K2K](../docs/decisions/I2K_SOURCE_ONLY_K2K_INFERENCE.md)에 따라 [서로 다른 Data의 I 1개 이상 → K 하나](../docs/decisions/MULTI_SOURCE_I2K.md)를 실제 구현·시험한다. I2K는 명시된 내용의 통합·동일 의미 재사용만 허용하며 원문에 없는 결론·추측을 만들지 않는다. 신규 I2K-origin Revision은 `is_inferred=false`다. [현재 실행 계획](../progress/T04_multi_source_runtime_execplan.md)에 코드·실제 모델·PG 결과를 기록하며 문서만으로 완료 처리하지 않는다.

실행은 여러 후보를 처리할 수 있고 I 하나도 여러 K의 근거가 될 수 있다. 문서별 전체 I 검토 의무, 실제 전달된 타 문서 I와 후보별 grounding을 구분한다. 단일 Data guard를 단순 삭제하지 말고 각 source를 검증하는 추가 profile/schema로 확장한다. source-specific 별개 실험을 합치지 않는다. 새로운 귀납·연역 결론은 검증된 전제 K를 받는 T07 범위이며 이 task의 I2K 결과로 우회 저장하지 않는다.

2026-09-11 최신 방향은 [LLM Wiki의 K → I → D 계층 검색](../docs/decisions/LLM_WIKI_RETRIEVAL.md)이다. 전체 I를 검토한 LLM이 활용할 가치가 있는 K를 미리 선택하며, 나머지 내용은 I 검색에 보존한다. [근거 공백 정책](../docs/decisions/I2K_DIRECT_SOURCE_EVIDENCE.md)에 따라 I2K에서 D2I 재실행·새 I 생성을 요구하지 않는다.

최신 source 입력 후속: [새 그룹 I 저장](../docs/implementation/GROUPED_INFORMATION.md)을 적용한다. I2K 준비는 frozen source algorithm으로 그룹 content/FP/block별 문자 범위/모든 media를 검증하며 과거 block I도 조회한다. 그룹 내부 원문 구간을 정확히 인용하고, `kind=text`인 그룹의 이미지를 제거하지 않는다. I 우선·원본 PDF 추가 조회와 실제 의미 모델·K 저장의 미완료 범위는 유지한다.

> 상태: IN_PROGRESS. 기존 [전체 I 선택·Terra I2K/N2E 저장](../docs/implementation/FULL_SOURCE_SELECTION.md)에 이어 [다중 Data Runtime](../docs/implementation/MULTI_SOURCE_RUNTIME.md)의 코드와 격리 PG 검증, 두 추가 논문의 실제 Terra I2K/N2E 실험을 수행했다. 격리 DB에 신규 K 11개·Edge 1개를 더했고 같은 의미 9개는 기존 Revision을 재사용했다. 실제 multi-Data 근거 K는 0개이며 의미 범위 오류·인용 부족·기존 오류 K 재검토가 남아 품질 통과로 판단하지 않는다. 기존 보존 DB의 0007 설치는 승인 대기다. 직접 D 근거·원본 PDF 모델 전달·검색/답변과 T04 전체 acceptance는 미완료다. ## 승인된 I 우선·원본 PDF 추가 조회 — 2026-09-11

[최신 사용자 계약](../docs/decisions/I2K_I_FIRST_SOURCE_ON_DEMAND.md)에 따라 PDF 기반 I2K는 **I의 content/provenance를 먼저 제공하고, 원문 확인이 필요하다고 판단되면 등록된 동일 Data의 원본 PDF를 제공한다.** Text/Image I 자체의 content는 초기 입력에 포함한다. 원본 PDF·전체 원본 페이지 companion은 자동 동봉하지 않는다. 앞선 원본 이미지 필수 동시 입력 계약은 이 범위에서 대체됐다. image200 MinerU와 원문/raster 보존은 유지한다.

처리 대상과 참고용 overlap을 구분한 projection에 exact I/Data/parse/block/page/source 범위를 연결한다. Figure·캡션·연속 문단은 I와 source refs로 조회한다. 현재 T03의 page/section/document-context는 retained 원본 이미지 descriptor를 포함하는 evidence 조회이며, 해당 JSON 전체를 초기 모델 입력에 그대로 보내지 않는다. 이 T04에서 실제 I payload 직렬화·model 호출·충실성 검증·K 저장을 구현한다.

Generator 또는 Validator는 I만으로 기호·수치·단위·조건·Figure 잘림·caption 소속 등을 확인할 수 없으면 이유/확인할 질문·관련 I/source refs와 필요 시 페이지/영역 힌트를 기록해 원본 PDF를 요청한다. 애플리케이션은 exact Data SHA와 등록된 원본 bytes를 확인해 제공한다. OCR용 image-only PDF로 조용히 대체하지 않는다. 실제 제공 파일 SHA·실행/profile·사용한 페이지/영역과 I를 결속하고, 요청/제공/사용/검증 완료를 구분한다.

필요한 원본을 읽지 못하면 관련 후보를 미해결로 유지한다. 알려진 discrepancy를 모델에 노출하고 모델이 요청하지 않았다는 이유로 해소 처리하지 않는다. I 밖에서 발견한 내용을 기존 I가 지원한다고 꾸미거나 canonical I를 자동 수정하지 않는다. 근거 공백 때문에 D2I를 재실행하지 않는다. 등록 원본에서 확인·검증한 내용은 직접 D grounding으로 K에 연결하고 누락/불일치 이력을 보존한다. 이 직접 grounding 경로는 추가 구현이 필요하며 현재는 원본 미제공 후보를 보류한다. I 우선 경로도 structured JSON 자체가 의미 정확성의 증명은 아니다.

실제 검증에는 최초 원본 PDF/전체 raster가 첨부되지 않음, Image I content 보존, 필요한 원본 요청/미요청 오류, exact Data/hash 결속, 요청 실패/미지원 provider, 추가 원문 사용 인용, 중복 후보 reuse, OCR 충돌·미충족 검증 의무를 포함한다. provider/model·PDF 지원 방식·kind registry를 이 부록에서 새로 확정하지 않는다.

## 문서 구조와 관련 I 검색 — 2026-09-10 후속

최신 [스크립트 청킹 정책](../docs/implementation/I2K_CONTEXT_POLICY.md)은 별도 소형 LLM 청킹·사전 검토를 사용하지 않는다. 그룹 역할/경계는 hint이며 대상 제외나 K 근거의 권위가 아니다. 역할 미확정 원문도 요청 범위의 target에 배정하고 source 보존·입력 계획·실제 전달·처리 완료를 구분한다. 필요한 근거가 창 밖이면 같은 D의 exact I·Figure/source refs 또는 원본 PDF 요청으로 보완하며 canonical I를 다시 쓰지 않는다.

일반 논문은 실제 I content/media·tokenizer·prompt·출력 한도 안이면 전체 I를 순서대로 제공하고, 초과하면 스크립트 절/문단 window로 분할한다. 원본 PDF가 필요할 때 추가 payload의 한도를 별도 확인한다. 첫 실제 평가는 I 기반 주장·근거 회수와 필요한 원본 요청/후속 검증을 확인한다. 필요할 때 동일 원본 조회 조건에서 스크립트 분할과 사람이 검토한 그룹을 비교한다. 그룹 라벨보다 주장·근거 누락, Figure 귀속, 수치/단위/조건/부정의 변화와 보류 적절성을 평가하고, 요청 빈도·실제 사용률·전체 토큰/시간을 별도로 기록한다. [구현된 조회](../progress/T03_section_projection_execplan.md)와 [이번 정책 변경](../progress/T03_i_first_policy_execplan.md)을 확인하며 기존 T03/T04 acceptance와 미정 registry/모델 계약은 유지한다.

전체 문서를 한 입력에 담아도 K 후보 전체가 한 응답에 완성된다고 가정하지 않는다. 출력 한도나 미검증 주장·필수 근거가 남으면 동일 source snapshot으로 이어서 추출·검증한다. source 배정/실제 전송/검증 완료를 구분하고 모든 K에 실제 사용한 exact I/source 범위를 남긴다. 절/문단 색인은 RAG·부분 재검증·긴 문서 분할에 유지한다. 이 문서 변경은 provider 실행·K commit 구현 완료가 아니다.

[사용자 입력 구성 정책](../docs/implementation/I2K_CONTEXT_POLICY.md)을 적용한다. 경계가 확인 가능한 경우 Abstract 전체와 Introduction 전체는 각각 논리적 그룹으로 묶고, 모호하면 역할 미확정 원문 범위를 유지한다. Results는 소절과 명시적 Figure·caption·panel 참조를 함께 가져온다. Markdown은 원본 heading 계층과 source 줄/문자 범위를 따른다. 원문 I를 재작성하지 않으며 같은 그룹이 context 한도를 넘으면 문단/정확한 source range별 하위 window로 계속 처리한다.

I2K의 seed I coverage와 추가 context 검색을 구분한다. 같은 D의 관련 문단·방법·Figure를 우선 찾고 corpus의 관련/상충 근거 경로도 유지한다. Embedding은 exact I/source range와 input digest/profile에 결속한 별도 검색 index로 구현한다. BGE-M3 기본값과 모델 교체 경계를 유지하며 유사도나 same-D 여부 자체로 지식의 동일성·진실·독립성을 승인하지 않는다. 현재 [229 I별 길이와 Figure 입력 시안](../output/t03-information-context/REPORT.md)은 실제 측정/검토 artifact이며 범용 section parser나 embedding 검색 실행 결과는 아니다.
