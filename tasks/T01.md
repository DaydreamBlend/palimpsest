## 현재 사용자 변경 — 이 task에 적용

U01–U03은 이미 적용된 요청이다. CLI-first/GUI-last, PDF parser=MinerU, Artifact Store/Canonical Store/Compiler Runtime을 유지한다. 이 task에서는 GUI를 만들지 않는다. P01–P12는 별도 승인 상태를 확인한다.

후속 U04/U05의 BGE-M3 기본 embedding/multi-vector reranking, 독립적인 모델 교체 경계와 MinerU 최신 안정판 선택도 유지한다. Qwen3 4B·8B는 향후 후보이며 아직 기본값/지원 완료로 표시하지 않는다.

U06은 D/I/K/W/P/B 및 각 변환의 모듈화를 확정한다. MODULE_BOUNDARIES의 책임·입출력·의존성·테스트 소유권을 후속 task에 적용한다. 공통 atomic commit과 결정론적 W2K는 유지하며 W2P/P2B를 새 Compiler Record subtype으로 승격하지 않는다.

U08 위임 수정은 [구조 해결 계약](../docs/decisions/ARCHITECTURE_FIXES.md)의 R01–R06/R09에 한정한다. R07/R08은 별도 사용자 선택을 기록하고 늦은 결정 재확인·기각 exact FP 조회로 적용했다. 전체 P/stack/profile 동결을 완료한 것은 아니다.

U09의 PostgreSQL 18/pgvector, Data 원본 SHA-256와 신규 opaque UUIDv7, 새 duplicate 거부/성공 retry 재생, 관리 복사 등록 및 Runtime Record를 보존하는 atomic 반영을 [저장 계약](../docs/decisions/STORAGE_IDENTITY.md)과 T02 SQL 초안으로 구체화한다. 초안은 미적용이며 driver·Docker 세부 실행 profile과 나머지 P10/P12를 자동 승인하지 않는다. 후속 U10으로 앱 언어 Python과 Docker 실행·배포는 확정했다.

후속 저장 설계 산출물은 [D/I/K/W 저장 스키마 v1](../docs/schema/DIKW_STORAGE_SCHEMA_V1.md)이다. 필드/typed FK/원자성/current-history/profile/단계별 migration을 구체화하고 P06 이름 및 effect-only matrix, identity·authority·scope 등의 미정 범위를 분리했다. 내부 물리안과 공개 의미 정책의 권위를 구분하며 이 문서 작성으로 다음 task나 실제 AT를 완료 처리하지 않는다.
